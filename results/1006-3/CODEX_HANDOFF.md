# 0. Macro objective and publication target

The highest-level goal is to produce a scientifically strong, globally relevant urban-science study with a realistic path toward **Nature Cities-level publication quality**.

This is an aspiration, not a guarantee of publication. The project must earn that level through:
- a globally relevant question;
- clear conceptual novelty;
- strong falsification and out-of-sample validation;
- large-scale/global evidence;
- transparent negative results;
- defensible data provenance;
- a contribution that changes how urban-history/urban-response relationships are understood.

Do not optimize the project around journal branding at the expense of scientific validity.

The preferred conceptual contribution is:

> Present-day urban state does not uniquely encode developmental history, but historical separability may or may not translate into environmental-response separability. The project tests where that information survives, where it fails, and whether it matters for transfer across cities.

The strongest publishable forms are likely:
1. a positive result showing that developmental history adds robust, global, out-of-sample information beyond present state and context for a defensible environmental response; or
2. a rigorous negative-result framework showing that developmental equifinality exists but does not translate into response separability under strong tests.

# 1. Non-negotiable scientific constraints

## Scale
- Stay at global / continental / city / urban-agglomeration scale.
- Do not drift into a neighborhood-scale or local case-study paper.
- Raster/pixel analysis is allowed only as an implementation layer to derive city/agglomeration variables.
- Final inference should remain about cities/agglomerations, not pixels.

## Scientific rigor
- Observational study only; no unsupported causal claims.
- Preserve strict temporal ordering where possible.
- Do not use post-treatment controls in the primary specification.
- Do not tune definitions after seeing the response just to rescue a hypothesis.
- Do not repeatedly re-slice failed data until something becomes significant.
- Use blocked/spatial validation, null models, sensitivity analyses, and out-of-sample metrics.
- Keep negative results as first-class scientific outcomes.

## Engineering / compute
- Prefer pre-aggregated global products when scientifically adequate.
- Avoid terabyte-scale raster workflows if a lower-volume city-level route exists.
- Stream/window large rasters; never require a giant in-memory global stack.
- Reuse existing code and validated modules.
- Build reusable basic capabilities so later rounds require only thin orchestration/config changes.
- Important scientific numbers should be generated by code and written to machine-readable outputs.

# 3. Core scientific notation

- S = present urban state
- H = developmental history
- C = environmental/geographic context
- R = environmental response

Questions:
1. Can cities with similar S,C have meaningfully different H?
2. Among similar present-day cities/context, does H add out-of-sample information about R?
3. If yes, can history-aware analogue transfer improve prediction?
4. Only after these gates, consider observation/sensing-network optimization.

Primary validity threats:
- H-S multicollinearity
- post-treatment control
- future-boundary leakage
- temporal overlap
- spatial autocorrelation
- climate confounding
- rural-reference contamination
- ontology/MAUP
- retrieval/gap-filling artifacts

# 6. Why the project pivoted

Failure diagnoses:
A. Response mixing: SUHI subtracts a rural reference; rural variation may obscure urban-side signal.
B. H representation: GHSL built-volume history is almost redundant with area history (per-epoch r ~0.977–0.990).
C. Scale/ontology mismatch: YCEO cluster vs UCDB centre; geometry sensitivities did not rescue Gate 2.

Selected primary pivot:
**A. Urban-side LST without rural-reference subtraction**

Backup:
**B. Independent morphological history**, only if a credible external multi-epoch source exists.

Do not rescue the old SUHI hypothesis by arbitrary re-slicing.
