======================================================================
1. SCIENTIFIC PURPOSE
======================================================================

This execution tests only GATE 1 of the candidate research programme.

It does NOT test whether urban development history affects heat,
flooding, vegetation, biodiversity, carbon, or any environmental response.

The sole scientific question is:

Can cities with similar present-day states and environmental contexts
have meaningfully different development histories?

Conceptually:

Can H remain meaningfully variable conditional on S and C?

or approximately:

H not approximately equal to f(S,C)

where:

H = historical urban development trajectory
S = present-day urban state
C = coarse background/context variables

This execution must NOT claim:

"history affects environment"

because no environmental response R is authorized.

======================================================================
2. CONCEPTUAL MOTIVATION
======================================================================

The candidate phenomenon is developmental equifinality:

different urban development pathways may converge toward similar
present-day urban states.

"Developmental equifinality" is a working description only.

Do NOT establish it as final terminology or claim it as a novel concept.

The future programme would only proceed if Gate 1 indicates that
historical trajectories retain meaningful variation after conditioning
on present state/context.

6. ENDPOINT YEAR
======================================================================

Do not assume 2020 automatically.

Inspect the actual verified UCDB temporal fields.

Choose the latest endpoint year T that allows:

- multiple strictly earlier observations for H;
- acceptable global completeness.

t < T

No future observations relative to T may enter H.

======================================================================
7. PRIMARY HISTORY VARIABLE
======================================================================

Prefer built-up surface/area trajectory if verified and sufficiently
complete.

Let:

B_i(t)

be built-up quantity for city i at historical time t.

Define normalized pre-endpoint trajectory:

h_i(t) = B_i(t) / B_i(T)

for:

t < T

The endpoint ratio 1 = B_i(T)/B_i(T) must NOT be included as a
historical feature.

The purpose is to represent development timing/trajectory shape while
separating it from final built-up scale.

Do not use GHS-AGE as the primary H in this execution.

Do not use environmental-response variables in H.

10. PRESENT-DAY STATE S
======================================================================

Construct nested present-state specifications, subject to actual data
availability.

S1:
present population
present built-up area/surface

S2:
S1 + present population density or equivalent non-identical density
information

S3:
S2 + present built volume or another verified 3D morphology variable

Important:

Do not include algebraically duplicate variables without documenting the
dependency.

For example, if density is exactly population / area, recognize that it
does not add independent raw information.

The nested specifications are intended to test whether historical
separability disappears as present-state description becomes richer.

13. EXPERIMENT 1 — HISTORY RECONSTRUCTION
======================================================================

Test how well present-day state/context predicts historical trajectory.

Conceptually:

H_hat = f(S,C)

This is NOT causal modeling.

Use simple models first.

At minimum compare:

- mean/null predictor
- linear or ridge model
- one nonlinear tree-based model if sample size supports it

Avoid extensive hyperparameter optimization.

Use strictly out-of-sample predictions.

Do not report in-sample fit as evidence.

Where possible use:

- random K-fold as descriptive baseline
- geographically blocked validation as primary robustness check

Possible blocked schemes:

leave-region-out
leave-continent-out

depending on sample support.

For multivariate H, evaluate both:

- per-epoch prediction performance
- aggregate trajectory prediction error

Report uncertainty across folds.

======================================================================
14. EXPERIMENT 1 INTERPRETATION
======================================================================

The question is NOT:

"Can machine learning predict history?"

The question is:

"How much historical trajectory information remains unresolved by
present-day state/context?"

If H is almost perfectly reconstructed out of sample from S,C:

this is evidence AGAINST proceeding with the intended history-memory
programme.

If substantial residual historical variation remains:

this supports proceeding to Gate 2, but does NOT establish an
environmental legacy.

======================================================================
15. EXPERIMENT 2 — PRESENT-DAY ANALOGUES
======================================================================

Standardize continuous S/C features using training/global rules
documented in the analysis.

Construct nearest-neighbour analogues in present-state/context space.

For each city identify one or more nearest present-day analogues.

Calculate:

D_SC

present-state/context distance

and:

D_H

historical trajectory distance.

Do not choose pairs based on environmental response because no R is
authorized.

Characterize:

distribution of D_H among low-D_SC pairs.

Determine whether substantial historically divergent present-day
analogues actually exist at scale.

21. GATE 1 DECISION CRITERIA
======================================================================

Do not invent a single arbitrary p-value threshold.

Evaluate Gate 1 using converging evidence.

Evidence FOR continuing includes:

- H cannot be near-perfectly reconstructed from S,C under geographic
  holdout;
- meaningful residual historical variation exists;
- strong present-day analogues with divergent histories are not rare;
- the pattern survives richer S specifications;
- the pattern is not eliminated by coarse geographic controls;
- results survive QC sensitivity analyses.

Evidence AGAINST continuing includes:

- H is essentially determined by S,C;
- apparent divergence disappears after richer S;
- twin candidates are extremely rare or driven by QC errors;
- geographic blocking destroys all apparent separability;
- the phenomenon is dominated by one region/product artifact.

Final Gate 1 classification:

PASS
MIXED
FAIL

Explain the evidence.

PASS does NOT mean the main scientific hypothesis is true.

It only authorizes consideration of Gate 2.
