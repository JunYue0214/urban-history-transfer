1. SCIENTIFIC PURPOSE
==================================================

Execution 1005-4 passed Gate 1 using the main GHS-UCDB R2024A product.

However, the main UCDB historical variables are aggregated using an urban-centre boundary delineated at the 2025 reference epoch.

This creates a serious methodological concern:

historical trajectories may partly reflect conditioning on a future/reference boundary rather than the true historical evolution of the urban centre.

Execution 1005-4 also acquired the official:

GHS_UCDB_MTUC_GLOBE_R2024A

Multi-Temporal Urban Centre product.

MTUC uses genuinely time-varying urban-centre delineations.

The sole scientific purpose of execution 1005-5 is therefore:

Determine whether the core Gate 1 finding from execution 1005-4 survives when urban history is defined using time-varying historical urban-centre boundaries.

This execution is a robustness gate.

It is NOT Gate 2.

Do NOT introduce an environmental response variable R.

Do NOT test whether history affects environment.

Do NOT make causal claims.
